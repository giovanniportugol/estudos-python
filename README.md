# Estudos Python

Repositório criado para registrar meus estudos acadêmicos em Python e lógica de programação.

## Sobre

Sou estudante de Análise e Desenvolvimento de Sistemas e estou em transição para a área de Tecnologia da Informação.

Este repositório tem como objetivo organizar exercícios simples de Python, com foco em:

- Lógica de programação
- Entrada e saída de dados
- Variáveis
- Condições
- Operações matemáticas
- Resolução de problemas

## Exercícios

- `ola_mundo.py` — primeiro exercício com entrada e saída de dados.
- `calculadora_simples.py` — calculadora simples com soma, subtração, multiplicação e divisão.
- `par_ou_impar.py` — verificador de número par ou ímpar usando condição `if/else`.

## Objetivo

Demonstrar minha evolução nos estudos de programação, praticando conceitos fundamentais e desenvolvendo raciocínio lógico.
